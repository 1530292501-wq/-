# 岩仓亚里亚 · 简体中文补丁

**版本：0.9.0-rc3（测试候选版）**

[下载补丁 ZIP](https://github.com/1530292501-wq/-/raw/refs/heads/main/downloads/Iwakura_Aria_zh-CN_0.9.0-rc3.zip)

适用已核验的 Windows x64 Steam Build 19808494（App 3197710）。安装器会核对原版资源哈希，版本不匹配时停止。

1. 退出游戏，将补丁 ZIP 解压到独立文件夹。
2. 双击 `安装汉化.cmd`，输入游戏文件夹路径。
3. 等待安装成功，启动游戏后使用日语／简体中文语言槽。
4. 需要还原时，关闭游戏并运行 `还原原版.cmd`。请保留游戏目录内的 `IwakuraAria_CN_Backup`。

查看[完整安装说明](patch/汉化补丁安装说明.txt)、[版本清单](patch/manifest.json)和[原有 rc3 验收记录](docs/地图修复验收记录_rc3.json)。`patch/` 内同时保留安装器 Python 源码、差分载荷、可执行安装器和第三方许可证。

已有安装、升级、还原及静态校验记录；全路线、排版、存读档和地图运行显示仍未完成验证。部分原文采用非性化简述，并非全部逐句忠实翻译；详情在补丁内“改写条目索引.json”（可能涉及剧情）。
