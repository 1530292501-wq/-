# 我亲爱的暗精灵 · 简体中文补丁

**版本：1.0-portable（解压安装版）**

[下载补丁 ZIP](https://github.com/1530292501-wq/-/raw/refs/heads/main/downloads/My_Darling_Dark_Elf_zh-CN_1.0-portable.zip)

适用已测试的 Windows Steam 版游戏 1.0（Ren'Py 7.5.3）。

1. 退出游戏，在 Steam 中选择“管理 → 浏览本地文件”。
2. 将补丁 ZIP 内全部内容解压到含 `darlingdarkelf.exe` 的游戏根目录，合并 `game` 文件夹。
3. 正常启动游戏，补丁自动启用简体中文。不要额外嵌套一层补丁目录。
4. 卸载时退出游戏，将 `game/tl/zh_CN_portable` 文件夹移出游戏目录。

查看[完整安装说明](patch/汉化安装说明.txt)和[原有校验记录](patch/汉化补丁校验.json)。`patch/` 内保留 Ren'Py 翻译源文件、兼容翻译层、字体与 OFL 许可证。

既有验收记录确认 4,700 条正文在干净原版与旧修复版两种环境中的映射，并验证开场画面。未逐屏通关核验全部游戏，也未逐图改绘所有内嵌文字。本次导入仅复核文件完整性，没有再次运行游戏。
